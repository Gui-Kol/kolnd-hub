## 3. O app Hub — fatos essenciais

- **Comandos** (em `kolnd-hub/`): `npm install` · `npm run dev` · `npm run build` · `npm run package` (gera `dist/Kolnd Hub Setup <versão>.exe`, ~305 MB com Mark LVII + MSI do Kloud Games) · `npm run typecheck` · `npm test` · `npm run lint` · `npm run format` · `npm run format:check` · **`npm run verify`** (typecheck + lint + format:check + testes) · **`npm run verify:build`** (verify + build) · **`npm run test:coverage`** (thresholds reais por área) · **`npm run test:e2e`** (Playwright + Electron; exige `--config=tests/e2e/playwright.config.ts` e **remover** `ELECTRON_RENDERER_URL`/`NODE_ENV` do shell, senão o Electron tenta o Vite; `KOLDND_HUB_E2E_CONTEXT` é um arquivo `.json` isolado por execução)
- **Versão:** `package.json` é a fonte única — **1.2.2** desde `b3eaaf78` (25/11/2026); `1.2.1` em `7c94b2ec` (24/11/2026); `1.2.0` em `d4fbee56`. Tags no git: só `v1.0`, `v1.1`, `v1.1.0-beta` — **nenhuma v1.2.x** (decisão do usuário: sem tags novas). `CHANGELOG.md` na raiz segue Keep a Changelog e tem `[1.2.2] - 2026-11-25` (registro de uso local, PR automático, ZeroTier e remoção em lote).
- **Config persistente:** `electron-store` em `%APPDATA%\kolnd-hub\config.json`, com schema e migrações versionadas (mais recente: **`'1.11.0'`** — garante a chave `usageLog` do registro de uso local, idempotente; antes `'1.10.0'` — **no-op** mantido para não abrir buraco na cadeia após a remoção do OpenOffice, `'1.9.0'` — `remoteAccess.mode`, `'1.8.0'`, `'1.7.0'` — HUD largura/escala, `'1.6.0'` — `hud.shortcut`, `'1.5.0'` — `benchmarkHistory`); migra automaticamente do `localStorage` na primeira execução; fallback `localStorage` se corrompido.
- **Primeira execução:** flag `%APPDATA%\kolnd-hub\first-run-complete.flag`; etapas: deps (Python/pip) → Python via winget (só se faltar) → MSI do Kloud Games via UAC (falha **não bloqueia**) → implantação dos programas → grava configs padrão.
- **Recursos embutidos NÃO vão para o git:** `kolnd-hub/resources/programs/MarkLVII/` e `kolnd-hub/resources/programs/kloud-games/` (MSI ~53 MB). São gerados por `kolnd-hub/scripts/build-*.ps1` e embutidos via `extraResources` (com `filter` para nunca levar segredos: `Mark-LVII/config/api_keys.json`, `config/certs/`, `config/whatsapp_web/`, `memory/`).
- **Dados do Mark LVII:** o `MarkLVII.exe` grava `config/` (chave de API) e `memory/` ao lado do próprio executável, em `resources/programs/MarkLVII/`. O Hub **não** define mais `MARK_LVI_HOME` nem espelha esses dados para `%APPDATA%`; eles são removidos junto com a instalação no desinstalador.
- **Distribuição:** instalação por usuário em `%LOCALAPPDATA%\Programs\Kolnd Hub` (sem admin), mas a 1ª execução dispara 2 UAC (winget-python e MSI). Risco de falso positivo de antivírus → assinatura de código é pré-requisito prático para distribuição pública. **Validação em máquina limpa está pendente.** **Decisão do usuário (18/11/2026): não assinar por ora** ("nada que gere custo") — o updater aceita `NotSigned` e recusa `HashMismatch`/`NotTrusted`; `REQUIRE_SIGNED_INSTALLER = false` vira `true` quando houver certificado.
- **Decisões registradas do usuário:** Playnite e SteamGridDB Manager foram **removidos** do projeto. Instalação do MSI do Kloud Games **exige UAC**. Desinstalações são destrutivas — confirmação explícita sempre.
- **Estrutura do código do Hub** (`kolnd-hub/src/`): `main/` (processo principal: janela/tray, primeira execução, instaladores, processos, store, updater, acesso remoto, benchmark, scanners de lojas) com subpastas **`games/`, `hud/`, `hwmon/`, `ipc/` (15 módulos), `uninstall/`** — **sem `office/` e sem `fps/`** (ambos removidos em 25/11/2026; ver estado atual); `preload/` (contextBridge, sandbox); `renderer/` (React: Dashboard, Biblioteca, Meu PC com Monitor/Benchmark/Energia, Configurações, FirstRunInstall, Big Picture + HUD overlay).
