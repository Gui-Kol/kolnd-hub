# Kolnd Hub v1.2.0

Data: 2026-11-24

## Destaques

- **Kloud Games atualizado para o Sunshine v2026.1123.40502**, mantendo o frontend e a identidade visual do Kolnd Hub:
  - suporte a encoders legados **MPEG-2** e **H.263+**;
  - nova opção **resolução máxima de stream** (`max_stream_resolution`);
  - captura **ScreenCaptureKit** e **VideoToolbox v2** no macOS;
  - correções de input absoluto, multiseat, portal/PipeWire e sessão gráfica no Linux;
  - dependências migradas para **CPM** (libvirtualhid, moonlight-common-c, nvapi e outras atualizadas);
  - a opção de doações continua removida.
- **OpenOffice removido do Hub**: página, IPC, contratos compartilhados, configurações e testes associados.
- **Acesso remoto via ZeroTier** no lugar do Tailscale.
- **Suíte de testes ampliada** para 1.893 testes unitários, cobrindo main, shared, preload, renderer/lib e hooks.
- **Melhorias de desempenho**: listagem de processos assíncrona e code splitting no renderer.

## Instalação

1. Baixe `Kolnd Hub Setup 1.2.0.exe`.
2. Execute o instalador (per-user, sem necessidade de administrador).
3. Na primeira abertura, o Hub instala o Python (se necessário) e o Kloud Games via MSI embutido.

O `KLOUD_GAMES.msi` também está anexado para instalação manual/administrativa, se necessário.

## Observações

- Os binários não são assinados com certificado Authenticode (`NotSigned`). O Hub aceita essa condição ao baixar atualizações, mas assinaturas inválidas ou ilegíveis são recusadas.
- Requer Windows 10/11 x64.
